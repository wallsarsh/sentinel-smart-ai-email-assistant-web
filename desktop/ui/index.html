SENTINEL · DESKTOP

Connect your email workspace

Connect to your existing Sentinel Web deployment. Mailboxes, AI providers, encrypted credentials, daily briefs and draft approval remain on that server.

HTTPS required. HTTP is accepted only for localhost testing.

How this works

Your account is authenticated by the Sentinel server. The desktop application stores the server address only. It never stores your email passwords or AI keys.

To connect Gmail or Microsoft 365, the desktop app opens your browser so OAuth and MFA work normally. After connecting, use Reload workspace from the tray. Change servers using Server settings.
